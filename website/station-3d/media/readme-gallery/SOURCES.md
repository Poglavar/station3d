# README runtime gallery

The four images in this directory are in-engine screenshots authored by
Poglavar Svemira and licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

They show Station3D running inside downstream Zagreb and Sloboda consumers.
The screenshots contain rendered world data whose attribution and database
licences remain with the data providers. In particular, map-derived content
includes © OpenStreetMap contributors under ODbL 1.0.

## Captures

- `zagreb-street.jpg` — captured on 22 September 2026 from the public Sloboda
  free-roam route near 45.809025, 15.9739. The consumer interface was hidden
  for the capture; the world renderer was unchanged.
- `split-st-duje.jpg` — captured on 22 September 2026 from the public Sloboda
  Split route. The consumer interface was hidden for the capture; the world
  renderer was unchanged.
- `split-rail-cab.jpg` — captured on 22 September 2026 from the public Zagreb
  transit planner, project 160, line 1, near route offset 46,587 metres. The
  application HUD remains visible because it is part of the rail-cab
  experience.
- `vis-mobile-campaign.jpg` — captured on 14 September 2026 from the Sloboda
  Vis introduction checkpoint at a 393 × 852 CSS-pixel viewport. The campaign
  objective and touch controls demonstrate the engine's mobile host UI.
